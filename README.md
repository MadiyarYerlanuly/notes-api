# Simple Notes API

## What it does
Это простой HTTP-сервис, написанный на чистом Python без сторонних библиотек. Он отвечает на три базовых эндпоинта:
- `GET /` — возвращает приветствие (Hello, World!).
- `GET /healthz` — проверка состояния (возвращает OK).
- `GET /notes` — возвращает захардкоженный список заметок в формате JSON.

## The Port
Сервис запускается на порту, который указывается в переменной окружения `PORT`. Если переменная не задана, по умолчанию используется порт `8080`.

## How to run
Чтобы запустить приложение, используйте специальный скрипт:
```bash
export PORT=8080
./scripts/run.sh
